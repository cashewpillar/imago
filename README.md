## Setup

Run PWA:

```shell
npx serve .
```

## Development

When you add a new `.html` file, register it with the PWA and index launcher by running:

```shell
node scripts/register-html.js
```

## Guide
1. Dexie.js for storage
1. Vanilla HTML and JS
1. Mobile-first
1. Light mode only
1. Core features
    - Import/export (UUID, idempotent records)
    - Reset and import
